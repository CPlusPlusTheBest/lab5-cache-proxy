Команди curl для перевірки кешуючого проксі-сервера
Сервер запущено так:
  node main.js -h 127.0.0.1 -p 3000 -c ./cache

=== Запуск без обов'язкових опцій (очікується помилка й код 1) ===
node main.js -p 3000 -c ./cache ; echo $?

=== GET: картинки ще немає в кеші (очікується 200, X-Cache: MISS) ===
curl -s -o /dev/null -D - http://127.0.0.1:3000/200

=== GET: повторний запит (очікується 200, X-Cache: HIT) ===
curl -s -o /dev/null -D - http://127.0.0.1:3000/200

=== Порівняння часу: з http.cat і з кешу ===
curl -s -o /dev/null -w "час: %{time_total} с\n" http://127.0.0.1:3000/404
curl -s -o /dev/null -w "час: %{time_total} с\n" http://127.0.0.1:3000/404

=== GET: неіснуючий код (очікується 404, у кеш нічого не потрапляє) ===
curl -i http://127.0.0.1:3000/999
ls cache
